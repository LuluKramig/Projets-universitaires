## Le projet en bref

Ce projet a pour objectif de créer une manière de représenter des graphes et des colorations de sommets en Java et de développer des algorithmes de coloration de graphes, particulièrement des graphes planaires. l'application produite permet de choisir le graphe parmi les graphes planaires disponibles et d'y appliquer des colorations.
Les algorithmes de coloration demandés et implémentés sont :
- L'algorithme de Welsh-Powell
- L'algorithme de 6-coloration des graphes planaires
- L'algorithme récursif de 5-coloration des graphes planaires

## Utilisation

Ce projet est sous la forme d'un projet développé sous Apache Netbeans. N'importe quel IDE ou moyen d'exécuter le Java à partir d'un répertoire projet peut l'exécuter.
L'application est composée d'une fenêtre, où il est possible de choisir le graphe planaire parmi ceux dans le jeu de données trouvable dans /dataset, ainsi que l'algorithme de coloration parmi les trois implémentés. L'application colorera les sommets.
Elle pourra aussi afficher les temps d'exécution de chacune des opérations d'affichage ou de coloration.

## Structure

Les diagrammes de classes sont contenus dans les fichiers XML ouvrables avec des visualiseurs de diagrammes UML.
