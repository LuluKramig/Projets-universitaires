
## Le projet en bref

Ce projet a pour objectif premier de programmer les règles d'un jeu de plateau appelé Biosphère7
Ce jeu, divisé en plusieurs niveaux de complexité, est un jeu de plateau sur un pavage de 14*14 carrés, représentant un terrain où des plantes poussent.

## Utilisation

Le jeu n'est pas jouable dans cet état. Il est cependant toujours testable grâce aux classes de test
