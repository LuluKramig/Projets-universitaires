## Le projet en bref

Ce projet a pour objectif de programmer une application IHM qui gère des personnages dans le jeu de rôle fictif BUTopia Mysteries.
Il est possible de créer des personnages, de les renommer, de les supprimer, d'ouvrir leurs fiches, de changer leur progression en termes de maitrise et d'indicateurs.
Des personnages peuvent passer des épreuves, et gagner de l'expérience, en fonction de leur réussite, qui dépend souvent de leur compétence.

## Utilisation

Ce projet est sous la forme d'un projet développé sous Visual Studio 2022 en C#.
Il est possible d'ouvrir le fichier SLN du projet sous Visual Studio pour pouvoir l'exécuter de manière à le vérifier, ou pour en créer l'exécutable.
